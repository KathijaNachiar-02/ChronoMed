# ChronoMed

AI-powered Medical Document Intelligence and Patient Timeline System.

## Project Flow

Medical Documents
        ↓
Document Processing / OCR
        ↓
AI Medical Information Extraction
        ↓
Structured Medical Events
        ↓
MongoDB
        ↓
Patient Timeline
        ↓
Evidence / Relationships / Conflicts / Q&A
